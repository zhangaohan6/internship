# 评测口径与面试说明

## 为什么不再用 45 道题证明整体效果

旧 45 题是原型探索，存在真值缺失、关键词评分和启发式“幻觉”标签，不能支撑整体可靠性。因此撤下原来的 96%、0.78 综合分、2.2% 幻觉率及零幻觉强结论。
新版不靠增加同义改写充数，而是拆分工具计算、多步执行、连续追问和异常处理，检查真实工具证据与最终输出。

## 本轮结果

2026-11-15 完成 150 条自建预留任务，每条重复两轮，共 300 次真实 API 试验。严格任务契约通过 281/300（93.7%）；两轮均通过 135/150（90.0%）。
统计查询 184/192；工作流/异常/检索联合任务 97/108。接口错误 0 次；300 次试验均收到真实模型响应。
运行时强制弃权 16 次、模型报告弃权 5 次，分开记录，不能把程序兜底算作模型主动识别能力。
本机 3 并发工作线程的单任务延迟 P50=3.73s，P95=6.13s；该延迟受网络、本地检索及模型服务影响。
通过官方 api.deepseek.com/v1 请求 deepseek-chat；所有任务实际返回 deepseek-flash。报告保存两者，服务端别名不等于不可变权重快照。
61 项自动化回归和 144/144 条工具层统计用例另行通过。工具层验证没有调用模型，不混入真实模型成功率。

## 划分与冻结

统计集：12 类查询 × 12 种人群条件，48 条开发、96 条预留，按查询族拆分。工作流集：9 类 × 8 变体，每类 2 条开发、6 条预留，共 18 条开发、54 条预留。工作流同族跨两组，不声称未见任务族泛化。
工作流覆盖人群差值、比率、结果驱动分支、多轮筛选、虚构患者预测比较、临时故障恢复、永久故障、边界与缺失输入、检索和统计联合任务。
首轮 18 个工作流开发试验通过 17 个，修正原始 JSON 格式约束后，完整开发集通过 61/66（其中工作流 18/18）。开发成绩与预留成绩分开。
正式评测保存代码、提示词、题集、CSV、本地模型、PDF 的哈希与代码快照。开始后未根据预留结果修改系统或评分器，未挑选失败题重新刷分。

## 评分要求

- 统计任务同时核验实际工具调用、完整筛选和事件参数、JSON 结构、单位与数值。
- 多步比较须引用模型此前已收到的两个来源结果；猜测同批新编号会被拒绝。条件分支须在收到首个结果后的模型步骤执行。
- 多轮任务核验首轮结果和追问条件；预测缺失年龄时先澄清，再使用补充后的已知特征。
- 异常由工具边界注入，模型仍真实调用；恢复、明确拒答及运行时兜底分别记录。这不是线上故障率评估。
- 引用核验文件、PDF 页码和逐字引文（40–220 字符）。本轮使用 lexical 检索；混合 RRF 另经本地功能验证。
- 正确拒答可满足异常任务的成功契约；正常统计任务未取得证据就拒答记为失败。
- 这是严格步骤与输出契约。用比例分子得到正确人数，或提前识别除零并拒答但未执行指定比较工具，也可能失败。失败不等于幻觉。

## 结论边界

自建查询、嵌套人群及同族变体相关，重复试验不是新独立样本。提示明确指定字段、编码、格式及部分工具，所以不是第三方盲测、临床验证或开放式真实用户请求评估。
预测比较的真值来自本地模型输出，评估的是调用与计算链路，不是患者结局。引文逐字一致不证明引用蕴含全部医学结论；没有医学专家标注集，不报告“临床准确率”或“零幻觉”。
名义 Wilson 区间保留在 JSON 中，但独立性假设不足，不用于临床泛化承诺。没有同口径旧版对照，不声称新版相对旧版提升某个百分比。
