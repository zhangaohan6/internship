不改预期答案、工具路径或数字容差。程序兜底不得归功于模型。

## 本轮代码变化

- 类型化答案合约：检查有限数值、单位和当前会话的证据编号。
- 原文引文校验：文件名、页码、40–220 字符摘录与检索结果一致。
- 校验失败最多两次模型修复，且共用全局步数预算；失败后结构化弃答。
- 工具参数的字段级错误提示、count 与 proportion 用法、ASA 与行走能力编码说明。
- Streamlit 新增可选择的数值证据校验模式。

详见 [设计、使用及参考项目](../../OUTPUT_VALIDATION.md)。校验器只读实际工具结果，
没有访问题目真值；它不判断所有自然语言语义、临床有效性或所选人群是否正确。

## 全部四次失败

| 试验 | 观察 |
|---|---|
| edge_cases-06，两轮 | 模型发现分母为零并弃答，但没有调用题目要求的比较工具，按严格步骤契约失败。 |
| retrieval_and_stats-03，第 1 轮 | 最终引用格式三次未通过答案合约，达到修复上限，程序弃答。 |
| context_refinement-02，第 2 轮 | 多轮筛选未完成要求的查询/证据流程，按契约失败。 |

没有选择性重跑以上失败。弃答任务可因正确处理异常而通过，不能把整体通过率理解为
所有题都返回了有效数字。任务由作者自建、同族相关；两轮不等于 300 个独立问题。
这不是临床评测，也没有“零幻觉”结论。模型服务别名随服务商变化，未锁定权重快照。
